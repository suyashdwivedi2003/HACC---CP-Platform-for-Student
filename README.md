# 🚀 HACC - CP Platform for Students

A full-stack Competitive Programming platform built to simplify contest management, student collaboration, and coding practice within college communities.

🌐 **Live Demo:** https://haccnitrr.netlify.app/

---

## 📌 Features

- 🔐 Secure Authentication (Register/Login)
- 📊 Personalized User Dashboard
- 🏆 Real-time Contest Management
- ⚡ Live Leaderboard Updates using WebSockets
- 🔔 Instant Contest Notifications
- 💬 Community Discussion Forum
- 👥 User Profiles
- 📱 Fully Responsive UI
- 🎯 Clean and Intuitive User Experience

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/your-username/HACC.git
```

Go to the project directory

```bash
cd HACC
```

Install frontend dependencies

```bash
cd client
npm install
```

Install backend dependencies

```bash
cd ../server
npm install
```

Run backend

```bash
npm run dev
```

Run frontend

```bash
npm start
```
